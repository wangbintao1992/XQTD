# Godot 肉鸽无尽模式 — 适配设计（R1）

- 日期：2026-10-27
- 目标：在 `godot-port` 分支现有 M1/M2 上纯新增肉鸽无尽，不改路径网络/自由布防骨架。
- 来源：用户 2026-10-27 的《国风象棋 · 肉鸽塔防》设计稿。

## 1. 落地范围

### R1（本次）

- `RunState` 局内状态：已获得词条、波次、本局标记；出局/重开清空。
- `TraitPool` 10+ 词条数据池 + 三选一抽取。
- 每波清空后三选一：选中的词条**实际生效**；`CardPicker` 显示词条名/描述。
- 真无尽：波次无限递增；数量每波 +15%、血量每波 +10%、每 5 波小幅提速。
- 词条效果：
  - 无蹩腿马（马无视马腿）
  - 无炮架炮（炮无需炮架，直射伤害 = 3）
  - 双车碾压（车伤害 ×2）
  - 杀招范围扩大（所有塔射程 ×1.25）
  - 冷却减半（所有塔攻击间隔 ×0.75）
  - 放置免棋气（放塔不扣棋气）
  - 击杀棋气 +50%
  - 开局/立即 +100 棋气
  - 苦肉计（生命 -5，全体塔伤害 ×1.5）
- HUD 显示本局已获得词条。
- 重开/返回首页清空词条与波次。

### R2（后续）

- 每 10 波棋局异变（炮弱化/马强化、车射程受限/小怪提速、逆风局、极限局）。
- 每 5 波精英黑棋（黑马/黑车/黑炮）+ 掉落高质量词条。
- 连环计（传染）、美人计（停顿）、绝杀减速、暴击等需要 debuff/状态机的词条。

### R3（后续）

- 杀招组合技：马后炮 / 双车错 / 重炮（阵型判定 + 墨浪清屏 + 概率）。
- 排行榜 / Java 后端 BattleReport 桩。

## 2. 关键取舍（可推翻）

- **沿用现有棋盘/路径/布防**：不切 10×9 网格与固定蛇形路径；现有 6 节点/8 边网络 + 20×20 吸附继续用。
- **沿用现有棋气/生命**：塔价先统一 50、生命 20；文档里的 10/8/9/6、100/-30 作为后续数值调优项。
- **玩家棋子先做车/马/炮**：士/象/兵放 R2 之后；文档 12 节与 19 节本身不一致。
- **天气保留**：M2 已做，R1 不改；文档把天气放二期，不冲突。
- **后端只留桩**：R3 再接；R1 不上报。
- **词条唯一**：同一词条不重复获得；全拿完后三选一从全部里随机（可能重复展示，但不再叠加）。

## 3. 数据与接口

- `RunState`（Autoload）：`traits: Array[String]`、`wave:int`、`add_trait(id)`、`has_trait(id)`、`reset()`、`signal traits_changed`。
- `TraitPool`：`TRAITS: Dictionary`（id → `{title, desc}`）、`ids()`、`title(id)`、`desc(id)`、`pick_three(owned)`、`apply_on_pick(id)`。
- `CardPicker`：`open_with_traits(ids, seconds, done)`、`selected_trait`；卡片显示 title/desc。
- `WaveManager`：`endless:bool`、`base_round:int`、`count_growth:float`、`hp_growth:float`；清空后先选词条。
- `PathSpawner`：`hp_mult`、`speed_mult`；`spawn_one` 按倍率生成。
- 塔：`apply_traits()` 重算伤害/射程/间隔；`RunState.traits_changed` 时由 `main` 遍历已放置塔刷新。

## 4. 验收

- 单测：RunState/TraitPool/词条效果/无尽波次/选卡词条。
- 集成：开局 → 连续过 2 波（用调试快速清场）→ 选词条 → 词条生效 → 波次 > 5 → 重开清空。
- headless 启动无错误。
